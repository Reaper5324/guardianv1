ADMINISTRATION

Manage Guardian

Local device

Configuration is intentionally read-only here. Change lists, profiles, bedtime, or remote settings through the protected administrator config workflow, then restart Guardian or wait for remote sync.

Uninstall Guardian

Enter the parent password created during installation. This restores saved adapter DNS and removes Guardian policies.

Management actions are local. Uninstall requires the parent password; Windows administrator access remains the recovery path if that password is lost.
